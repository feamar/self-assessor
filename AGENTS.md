# Self Assessor agent instructions

This repository contains a **source skill**, not the target of an assessment. On a request to `Start https://github.com/feamar/self-assessor/`, read [START.md](START.md), then the full [Software Delivery Assessment skill](.github/skills/software-delivery-assessment/SKILL.md) and its referenced guidance.

Before assessment, complete the mandatory High reasoning preflight in START.md for Visual Studio or VS Code; ask the developer to confirm if the setting is not verifiable. Assess the software repository open in the developer's working environment, not `self-assessor`, unless the user explicitly selects this repository. Do not claim a remote skill was loaded without actually retrieving its content; do not run or modify code without appropriate authorization.
