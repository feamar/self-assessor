# ADR 0002: Retire D06 — Metric publication and transparency

**Status:** Accepted  
**Original dimension:** D06 — Metric publication and transparency  
**Disposition:** Retired

## Context

Transparency is a quality requirement for every metric, not a separate delivery outcome.

## Decision

Remove this as a standalone assessed dimension. Apply transparent definitions and reproducible sources to every chosen metric; don't score publication activity.

## Consequences

The assessor does not score the former metric or request its collection by default. Relevant evidence may still be used to explain measured outcomes or assess a material risk. This decision can be revisited if a simpler, transparent outcome metric is identified.
