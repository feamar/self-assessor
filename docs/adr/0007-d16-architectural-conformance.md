# ADR 0007: Retire D16 — Architectural conformance

**Status:** Accepted  
**Original dimension:** D16 — Architectural conformance  
**Disposition:** Retired

## Context

A global conformance percentage depends on specialist interpretation and is not an outcome; investigate architecture only where it demonstrably affects change or risk.

## Decision

Remove this as a standalone assessed dimension. Ask about concrete architectural blockers or risk only when lead-time, reliability or control evidence justifies investigation.

## Consequences

The assessor does not score the former metric or request its collection by default. Relevant evidence may still be used to explain measured outcomes or assess a material risk. This decision can be revisited if a simpler, transparent outcome metric is identified.
