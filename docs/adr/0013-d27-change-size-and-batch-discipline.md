# ADR 0013: Retire D27 — Change size and batch discipline

**Status:** Accepted  
**Original dimension:** D27 — Change size and batch discipline  
**Disposition:** Retired

## Context

Small PRs are an input, not an outcome; use lead time and delivery consequences instead.

## Decision

Remove this as a standalone assessed dimension. Review batch size only as causal context for poor lead time or failure outcomes.

## Consequences

The assessor does not score the former metric or request its collection by default. Relevant evidence may still be used to explain measured outcomes or assess a material risk. This decision can be revisited if a simpler, transparent outcome metric is identified.
