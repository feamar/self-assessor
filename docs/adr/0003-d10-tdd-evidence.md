# ADR 0003: Retire D10 — TDD evidence

**Status:** Accepted  
**Original dimension:** D10 — TDD evidence  
**Disposition:** Retired

## Context

Adherence to red-green-refactor is a prescribed method; judge demonstrated test effectiveness instead.

## Decision

Remove this as a standalone assessed dimension. Ask whether important failures would be caught by the tests; do not require a particular test-writing chronology.

## Consequences

The assessor does not score the former metric or request its collection by default. Relevant evidence may still be used to explain measured outcomes or assess a material risk. This decision can be revisited if a simpler, transparent outcome metric is identified.
