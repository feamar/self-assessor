# ADR-0021: Three-paragraph leadership report

**Status:** Accepted

## Context

Lead developers and CTOs need a brief verdict, its evidence, and improvement priorities rather than long scorecards.

## Decision

Default report is **at most three paragraphs and one page**: (1) qualitative grade and observed results; (2) confidence, history and important risks; (3) improvements. Do not print numerical scores unless expressly requested. Detailed evidence, optional comparisons and ready-to-use agent skills are separate deliverables.

## Consequences

The assessment remains decision-ready and explicit about missing outcomes. A concise report cannot be mistaken for an exhaustive technical audit.
