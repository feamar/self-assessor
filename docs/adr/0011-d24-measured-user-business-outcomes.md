# ADR 0011: Retire D24 — Measured user/business outcomes

**Status:** Accepted  
**Original dimension:** D24 — Measured user/business outcomes  
**Disposition:** Retired

## Context

A generic 'business improvement' measure lacks one transparent, universal definition; retain service-specific outcomes when naturally measured.

## Decision

Remove this as a standalone assessed dimension. Use concrete product/service-specific outcomes if available; first-pass acceptance can capture fitness to requested demand.

## Consequences

The assessor does not score the former metric or request its collection by default. Relevant evidence may still be used to explain measured outcomes or assess a material risk. This decision can be revisited if a simpler, transparent outcome metric is identified.
